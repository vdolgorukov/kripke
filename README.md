# Truth of Formulas in a Kripke Model

Practice page: for each modal formula, mark the worlds of a Kripke model where it is true, then check your answer. English by default, with a switch to Russian.

Live page: https://vdolgorukov.github.io/kripke/ (Russian: https://vdolgorukov.github.io/kripke/#lang=ru)

---

Тренажёр: для каждой модальной формулы отметьте миры модели Крипке, в которых она истинна, и проверьте ответ. По умолчанию на английском, есть переключатель на русский.
